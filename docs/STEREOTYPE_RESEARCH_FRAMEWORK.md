# 互联网人格刻板印象调研框架

> 目标：让人格副本“有据但不端着”。  
> 本文档用于指导后续 16 型人格副本的内容调研、选项设计、支线设计和死亡报告写作。

---

## 1. 为什么需要调研

人格副本馆不是严肃心理测评，但也不能纯靠编。

我们的内容要做到：

```text
不追求科学诊断，但追求互联网共识。
不追求绝对准确，但追求玩家觉得“像”。
不做心理咨询，但要让每个选项都能说得通。
不照搬资料，但要把常见印象转译成好玩的剧情机制。
```

也就是说，项目使用的是“互联网人格印象”，不是“临床人格判断”。

## 2. 资料来源分层

后续每个人格副本的内容，建议分 4 层来源。

### 2.1 A 层：官方/基础类型描述

用途：确定人格底色，防止跑偏。

关注内容：

- 四字母类型偏好；
- 典型优势；
- 决策方式；
- 社交能量；
- 信息处理方式；
- 关系中的基础倾向。

使用方式：

```text
只作为底稿，不直接写成题目。
```

例如：

- INFJ：意义感、连接、洞察、价值感；
- INTJ：独立、长期规划、高标准、逻辑评估；
- INFP：理想、价值、真诚、意义；
- ENTP：新奇、概念、反问、辩论、反套路。

### 2.2 B 层：大众人格网站/文章

用途：补充可读的人格特征和关系向表达。

关注内容：

- 常见优点；
- 常见弱点；
- 恋爱关系描述；
- 沟通偏好；
- 压力反应；
- 常见误解。

使用方式：

```text
可以吸收观点，但不要照搬文案。
```

### 2.3 C 层：社区讨论

用途：获取互联网真实争议和自嘲梗。

来源包括：

- Reddit 的 r/mbti、r/infj、r/entp 等；
- 知乎、豆瓣、小红书、B站评论区；
- MBTI 主题社区、论坛、视频评论区。

关注内容：

- “这个梗准不准”；
- “这个刻板印象哪里让人烦”；
- “这个人格最讨厌别人怎么理解自己”；
- “自认某人格的人如何自嘲”；
- “其他人格如何吐槽这个人格”。

使用方式：

```text
重点不是证明它是真的，而是识别它是不是被广泛玩过、吵过、吐槽过。
```

### 2.4 D 层：meme/短视频/梗图

用途：确定娱乐化表达方式。

关注内容：

- 哪些标签最容易传播；
- 哪些人格梗有视觉化潜力；
- 哪些吐槽适合做死亡报告；
- 哪些句式适合短视频钩子。

使用方式：

```text
负责“好玩”，不负责“严肃正确”。
```

## 3. 依据等级

每条内容进入题库前，最好标记一个依据等级。

| 等级 | 名称 | 说明 | 可以怎么用 |
|---|---|---|---|
| S | 高共识梗 | 官方底色 + 多平台社区都常见 | 可作为副本主机制 |
| A | 常见印象 | 多篇文章/社区讨论反复出现 | 可作为关卡雷点 |
| B | 社区争议梗 | 有人认同也有人反驳 | 可作为隐藏支线或吐槽 |
| C | 单点灵感 | 只在少量评论/视频看到 | 可作为彩蛋，不做主线 |
| D | 纯脑洞 | 没有资料支撑 | 暂不进入题库 |

举例：

```text
INFJ door slam：B/A 之间
原因：社区里非常常见，但也有大量讨论认为它不是 INFJ 独有，甚至只是被神化的 meme。
适合用法：可以作为“终极门锁/门关上”的副本意象，但不能写成“所有 INFJ 都会这样”。
```

## 4. 选项设计原则

每道题至少提供 6 类候选反应，再从中挑 4 个给用户。

这样题库才不会薄。

### 4.1 六类基础选项

| 类型 | 功能 | 例子 |
|---|---|---|
| 核心雷点 | 直接踩中人格最讨厌的东西 | “你是不是又在冷暴力？” |
| 常见错误 | 很多人会这么回，但不够好 | “我真的不是那个意思，你听我解释。” |
| 伪正确 | 表面成熟，实则埋雷 | “行，那你冷静吧。” |
| 高质量选择 | 暂时存活或加分 | “我先不逼你回应，但我会认真想这件事。” |
| 逃避选择 | 回避冲突，延迟死亡 | “我们别聊这个了。” |
| 反向作死 | 出于自尊或博弈，容易被截图吐槽 | “那你找别人去吧。” |

### 4.2 每个选项都要有行为标签

选项不能只写对错，要标记它暴露了用户什么模式。

```ts
pattern:
  | 'self_proof'     // 证明自己
  | 'pressure'       // 逼对方给答案
  | 'avoidance'      // 回避
  | 'control'        // 控制
  | 'empathy'        // 共情
  | 'logic'          // 逻辑化
  | 'playful'        // 玩笑化
  | 'attack'         // 反击
  | 'surrender'      // 无边界投降
```

### 4.3 每个选项都要写三层反馈

```text
1. TA 的即时反应
2. 系统识别出的用户模式
3. 对后续剧情的影响
```

例子：

```text
选项：我真的不是那个意思，你听我解释。

TA 的反应：
TA 沉默了几秒，“正在输入”出现，又消失了。

系统识别：
证明欲 +1。你又把重点放回了自己身上。

后续影响：
如果证明欲累计到 2，第 3 关触发“解释成瘾”专属支线。
```

## 5. 支线设计原则

### 5.1 不做巨型分支树

不要做 4^5 的爆炸剧情树。

正式策略：

```text
固定主线 + 状态变量 + 条件台词 + 多结局
```

### 5.2 支线主要体现在 5 个地方

1. TA 的补充台词；
2. 系统提示；
3. 是否触发隐藏死亡；
4. 是否开放特殊选项；
5. 最终结局类型。

### 5.3 支线触发例子

#### INFJ

```text
如果 self_proof >= 2：
TA 在第 3 关多说一句：
“你看，你现在又开始解释了。”

如果 boundary_respect <= -2：
第 4 关触发“边界失效”死亡报告。

如果 empathy >= 3 且 pressure <= 0：
最终触发隐藏通关：
“这次我感觉你真的听见了。”
```

#### INTJ

```text
如果 emotional_noise >= 2：
系统提示：防火墙升级。

如果 plan_clarity >= 3：
第 4 关开放“观察期方案”选项。

如果 credibility <= -2：
触发“申请被永久驳回”。
```

#### INFP

```text
如果 meaning_respect <= -2：
触发“现实铁锤”死亡线。

如果 tenderness >= 3：
最终结局从“普通通关”变为“慢修复”。

如果 dream_damage >= 3：
TA 会说：
“我不是不想相信你，是不知道还能不能相信以前那个故事。”
```

#### ENTP

```text
如果 debate_trap >= 2：
系统提示：你已经进入 TA 的辩论场。

如果 playful >= 2 且 self_stability >= 2：
开放“轻松接梗但不逃避问题”的高级选项。

如果 attack >= 2：
触发“小学鸡互啄”死亡线。
```

## 6. 16 型人格素材库初稿

> 这是第一版互联网印象表，不是最终结论。后续每个人格都要继续补资料。

| 人格 | 互联网核心印象 | 副本主题 | 可设计雷点 | 可设计通关方式 |
|---|---|---|---|---|
| INFJ | 深、敏感、洞察、门关上、旧伤 | 挽回 INFJ 挑战 | 解释、逼问、轻视感受、无视边界 | 接住感受、尊重空间、承认旧模式 |
| INTJ | 冷、理性、规划、高标准、防火墙 | 破解 INTJ 防火墙 | 情绪绑架、无方案、低可信承诺 | 给方案、给证据、稳定执行 |
| INFP | 理想、柔软、价值感、旧梦、滤镜 | 修复 INFP 旧梦 | 现实铁锤、嘲笑矫情、否认变化 | 尊重意义、温柔承认、慢修复 |
| INTP | 离线、逻辑、低功耗、懒得解释 | 唤醒 INTP 离线线程 | 追问、情绪轰炸、要求秒回 | 给空间、低压沟通、具体问题 |
| ENFP | 热情、自由、灵感、风、三分钟热度 | 抓住 ENFP 的风 | 控制、扫兴、否定热情 | 给予自由、参与想象、稳定回应 |
| ENTP | 辩论、反问、玩笑、反杀、脑洞 | 别被 ENTP 反杀 | 破防、防御、较真、无聊 | 接梗、稳定、自嘲、具体行动 |
| ENFJ | 照顾者、外热内耗、情绪雷达 | 卸下 ENFJ 的笑脸 | 把照顾当理所当然、忽视消耗 | 看见 TA 的累、主动承担 |
| ENTJ | 目标、效率、掌控、最终审批 | 通过 ENTJ 审批 | 卖惨、拖延、没有结果 | 明确目标、交付结果、尊重效率 |
| ISFJ | 细心、照顾、忍耐、记小事 | 拦住 ISFJ 安静撤退 | 忘记小事、理所当然、长期忽略 | 记得细节、稳定回馈、真诚感谢 |
| ISTJ | 规则、责任、信用、秩序 | 重建 ISTJ 信任档案 | 失约、临时变卦、口头承诺 | 可靠、准时、可验证改变 |
| ISFP | 安静、感受、美感、不解释 | 听见 ISFP 的沉默 | 逼表达、否定感受、控制选择 | 温和陪伴、尊重节奏、少压迫 |
| ISTP | 冷静、动手、抽离、维修模式 | 维修 ISTP 断联系统 | 黏人、追问、戏剧化表达 | 直接、低压、给自主空间 |
| ESFJ | 热情、关系秩序、仪式感、被需要 | 补交 ESFJ 的仪式感 | 冷落、不给回应、公开忽视 | 公开重视、及时反馈、表达感谢 |
| ESTJ | 结果、规则、执行、管理 | 接受 ESTJ 最终考核 | 空话、低效、没担当 | 拿结果说话、承担责任 |
| ESFP | 热闹、快乐、当下、讨厌沉重 | 别让 ESFP 快乐下线 | 沉重说教、限制自由、扫兴 | 轻松修复、一起行动、别太压迫 |
| ESTP | 行动、刺激、自由、反控制 | 追上 ESTP 失控局 | 试图管住、道德审判、拖慢节奏 | 直接、有趣、不控制、给挑战 |

## 7. 首发四人格的深入调研方向

### 7.1 INFJ

重点调研词：

```text
INFJ door slam
INFJ boundaries
INFJ relationship misunderstood
INFJ emotional safety
INFJ old wounds
INFJ authenticity
```

要提炼的不是“INFJ 真的会不会 door slam”，而是：

```text
为什么这个梗能被传播？
为什么它适合做成“门锁/旧伤/最后告别”的副本意象？
哪些说法会让 INFJ 玩家觉得“不是所有 INFJ 都这样，但这个梗我懂”？
```

### 7.2 INTJ

重点调研词：

```text
INTJ relationships
INTJ high standards
INTJ emotional expression
INTJ trust
INTJ planning
INTJ cold stereotype
```

要提炼：

```text
防火墙、审批、风险评估、观察期、行动方案。
```

### 7.3 INFP

重点调研词：

```text
INFP idealist
INFP sensitive stereotype
INFP values relationship
INFP misunderstood
INFP dreamer meme
```

要提炼：

```text
旧梦、滤镜、意义感、理想坍塌、柔软但倔。
```

### 7.4 ENTP

重点调研词：

```text
ENTP debater stereotype
ENTP devil's advocate
ENTP argumentative meme
ENTP playful relationships
ENTP debate trap
```

要提炼：

```text
辩论场、反杀、玩笑试探、接梗能力、不要把轻松局打成审判局。
```

## 8. 内容审查标准

每一道题上线前，都要过 5 个问题。

```text
1. 这个场景是不是该人格常见印象能支撑的？
2. 四个选项是不是覆盖了不同玩家模式，而不是同一种错误换说法？
3. 是否至少有一个“看似正确但埋雷”的选项？
4. 这个选择是否会影响后续台词、变量或结局？
5. 死亡报告是否足够有梗，但没有变成人身攻击？
```

如果 5 个问题里有 2 个答不上来，就不要进题库。

## 9. 资料记录模板

后续每条调研资料都按这个格式记录。

```markdown
## 资料标题

- 来源：
- 平台：官方 / 文章 / Reddit / 知乎 / 小红书 / B站 / TikTok / YouTube / 其他
- 人格：INFJ / INTJ / ...
- 关键词：
- 摘要：
- 可转译成的玩法：
- 依据等级：S / A / B / C / D
- 注意事项：
```

示例：

```markdown
## INFJ door slam

- 来源：多个 MBTI 社区讨论
- 平台：文章 + Reddit
- 人格：INFJ
- 关键词：door slam、边界、长期失望、最后切断
- 摘要：这是一个非常流行但有争议的 INFJ 梗。常见说法是 INFJ 在长期边界被忽视后切断关系，也有人反驳这不是 INFJ 独有。
- 可转译成的玩法：终极门锁、旧模式识别、门没有继续关上、最后告别
- 依据等级：B/A
- 注意事项：不要写成“INFJ 必然这样”，要写成“社区流行意象”。
```

## 10. 下一步执行计划

### 10.1 调研任务

先集中调研 4 个首发人格：

1. INFJ；
2. INTJ；
3. INFP；
4. ENTP。

每个人格至少整理：

- 10 个常见标签；
- 10 个关系雷点；
- 10 个玩家常见错误；
- 10 个死亡报告标题；
- 5 个可用副本意象；
- 5 个隐藏支线触发条件。

### 10.2 内容任务

先把 INFJ 做成样板。

INFJ 样板题库目标：

```text
5 关主线
每关 6 个候选选项
每题上屏 4 个选项
每个选项有变量影响
至少 4 个结局
至少 5 个隐藏 flag
至少 8 条条件台词
```

### 10.3 代码任务

下一步代码不急着加新人格，先升级引擎：

```text
isCorrect → outcome
单次死亡 → 变量累计
固定成功文案 → 选择后反馈面板
单一通关 → 多结局
无记忆 → flags + pattern 识别
```

## 11. 最终内容原则

```text
资料是地基，梗是外壳，剧情是灵魂。

没有资料支撑的梗不要当主线。
没有剧情影响的选择不要上线。
没有人格差异的题目不要复用。
没有转发欲的结果页不要发布。
```

最终目标：

> 让用户觉得：它不是严肃的，但它不是乱写的；它没有用，但它好玩得像真的。
